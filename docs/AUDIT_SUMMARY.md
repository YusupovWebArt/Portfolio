## 3. Принятые компромиссы и остаточные риски

1. **CSP Next.js:** `script-src 'unsafe-inline'` снижает защиту от XSS. Строгий вариант с nonce потребует динамического рендера.
2. **CSP зеркала:** `font-src data:` для встроенных шрифтовых подмножеств.
3. **История git:** содержит ранее публиковавшиеся контакты, в том числе открытым текстом. Переписывание истории дает ограниченный эффект, надежнее ротируемые каналы (алиас почты, WhatsApp Business).
4. **Защита контактов:** Base64 и раскрытие по клику только повышают стоимость сбора. Скрейпер с исполнением JS и кликом получит данные.
5. **Лимитер:** окно фиксированное (до двойного лимита на границе окна); при недоступности Upstash режим на инстанс на serverless деградированный, а не распределенный. Глобального предела расходов в коде нет, нужен лимит расходов в проекте OpenAI и правило WAF.
6. **Проверка Origin** не является аутентификацией: скрипты подделывают заголовок.
7. **Бюджет:** начальный путь использует около 98% лимита из-за eager-чанка `locales` (три языка, около 105 КБ).
8. **Prompt injection:** защита многослойная, но не абсолютная.
9. **Сканер утечек в CI** проходит по HTML-файлам Vite; SSR-вывод Vercel покрыт только `renderToString`-тестом.
10. **Контраст** посчитан по палитре Tailwind v3, в проекте v4.3.3, значения могут отличаться в пределах десятых долей.
11. **Класс-утилиты разных поколений** (например, `bg-opacity-*` из v3 и `w-8.5` из v4) в проекте смешаны; часть может молча не работать. Проверка не проводилась.
12. **Контент 911mg:** достоверность утверждений подтверждена владельцем и независимо не проверялась.
13. **Конституция:** правка принципа 3 внесена по заявлению владельца.
